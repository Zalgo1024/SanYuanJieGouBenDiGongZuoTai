## 一、工作流本质（最高前提，唯一准绳）

**全自动写报告**：用户只丢出关键词或相关链接 → AI 智能体读取本项目的方法论（三元结构理论 skill）→ 自动写完整份报告 + 利益关系网络 → 排版输出。
【"我丢出关键词或者相关链接即可，然后读取了这个项目的ai智能体就可以自动帮我写好整个报告和利益关系网络"】【"程序从头到尾都帮我自动写，不是我自己写"】

→ 系统里**不存在**"用户手写成稿"环节；AI 是写手，内核只负责排版渲染。

---

## 二、功能需求（按用户故事组织）

| # | 我要什么 | 说明 |
|---|---|---|
| F1 | **丢关键词 → 自动出完整报告** | 输入一个主题/关键词，系统自动联网找素材、写报告、出关系图 |
| F2 | **丢链接 → 自动抓取内容写报告** | 粘贴 URL，自动抓该页公开正文当素材写报告 |
| F3 | **自动联网抓取相关信息** | SaaS 能自动抓取相关网络信息（搜索引擎 → 抓网页正文 → 去重 → 作素材），报告附录带可点击来源 |
| F4 | **5 种报告类型全部真能用** | 政策 / 事件 / 组织 / 舆情 / 组合，选了哪种就出哪种的深度报告（章节骨架与所选类型一致，不搞假映射） |
| F5 | **三态关系图正确显示** | 利益网络（散点力导向）/ 组织架构（层级树）/ 资金或流程（左→右流），一篇报告多张图全显示 |
| F6 | **报告展览页（核心体验）** | 报告生成后进一个专门、好看的前端页面：可下载 Word/PDF、可查看正文与三态图 |
| F7 | **报告可改 + 修改留痕** | 展览页上可手动改，也可让 AI 按指令再改一版；**每次修改都标记是在什么时候改的**（时间戳/版本），可回看可回滚 |
| F8 | **案例可编辑** | 前端能看到 cases 案例库，可预览、可套用模板、可直接编辑（不是不可动的范文） |

## 三、五件事拍板（D1–D5）

| # | 事项 | 拍板内容 |
|---|---|---|
| D1 | 联网抓取源 | 直连搜索引擎；优先**零成本、零 Key** 的方式（DuckDuckGo），配置 Key 可自动升级 Bing/Brave |
| D2 | 抓取范围 | **只抓公开内容**；不搞登录态、不抓需要登录才能看的东西 |
| D3 | 报告类型机制 | **维持现状双轨**（前端选类型→决定 AI 怎么写；内核按章节标题自动识别类型）；加一致性护栏；不改变"全自动写" |
| D4 | 案例/报告编辑 | 案例可前端编辑；报告有专门好看展览页、可下载、可手动改/让 AI 改、**改了标时间戳**、可回滚 |
| D5 | 启动方式 | **双击 start.bat 启动**，本地优先、绑 127.0.0.1，数据全在本机 |

## 四、落点要求（最重要的裁决）

**以上所有需求，都要在「分析skill」这个项目里落地**——不是隔壁目录。
【"我今天跟你说的所有，都是我想要在skill分析 这个项目搞得"】

→ 分析skill 必须是：**完整、自包含、能独立启动的项目**：
- 前端源码就在项目里（不是只剩编译快照）
- 前后端同仓、接通、一键启动
- API 契约一致、任务稳定（崩溃能恢复）、测试全绿
- 项目管理是实的（有草稿/版本，不是展示外壳）

## 五、验收标准（怎么算"成了"）

1. 双击**分析skill 目录**里的 start.bat → 浏览器打开 → 界面能用
2. 丢关键词生成 1 篇：来源≥3、附录可点击、Word/PDF 可下载、三态图正确
3. 丢链接生成 1 篇：自动抓正文成稿
4. 5 种类型逐一生成：选的类型 = 出的报告类型
5. 展览页：手动改 + AI 再改各一次 → 版本时间线≥3 版、有时间戳、可回滚
6. 案例库：预览 / 套用 / 编辑都可用
7. 代码全在分析skill 仓库，git 可追踪，测试全绿
