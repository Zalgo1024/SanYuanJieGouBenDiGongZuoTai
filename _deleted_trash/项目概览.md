# 三元结构理论分析系统 — 项目概览

> 整理自 2026-08-01 全项目通读（Senior Developer 接管后复核）

## 一句话定位
把"三元结构理论"（生存—繁衍—逆反—利益四维框架）做成**自动写稿 + 自动排版**的分析引擎：丢关键词/链接 → AI 读方法论 → 自动产出完整报告 + 利益关系网络 → 内核渲染 Word/PDF/交互式 HTML。

## 当前形态（2026-08-01 后）
- **前端已整体移除**（用户裁决：结构混乱、质量差）。项目现为 **内核（命令行）+ 后端 API（FastAPI 8000）** 两层。
- 范围严格限定在 `三元结构理论 分析skill脚本程序/` 内；外部 `Web 分析模型`、`Web 分析模型 codex`、`三元结构理论 展示页` 等仓库未动。

## 内核（kernel，根目录）
| 文件 | 职责 |
|---|---|
| `engine.py` | 编排器。`CaseAnalysisEngine.export_from_text(title, body, output_dir=, slug=, overwrite=, tone=)` 是**唯一正式出口**；先 `auto_number_headings` 自动编号 → `parse_report` → 渲染 Word → 转 PDF。 |
| `parser.py` | Markdown → 结构化数据。`_SECTION_IDS` 决定章节路由（政策/事件/组织/舆情/组合 五态）。 |
| `docx_renderer.py` | Word 渲染（富文本/图表/页眉页脚/TOC/自动章节序号）。附录列表用数字编号。 |
| `viz_network.py` | 利益关系网络图。**三态**：`network`(力导向) / `org`(树形层级) / `flow`(左→右流程)。HTML 内联 vis-network，离线可开。 |
| `pdf_converter.py` | PDF 转换（LibreOffice 优先，Word COM 兜底）。 |
| `config.py` / `theory_config.json` | 理论配置（概念池/利益类型/可视化/排版）。**不要随意改 theory_config.json**。 |

### 报告类型（零参自动路由，由章节 ID 触发）
| 类型 | 触发章节 | 结构 |
|---|---|---|
| 政策分析 | `policy_portrait` 等 | 8 段式 |
| 事件/案例 | `case_portrait` / `event_portrait` | 5 段 / 深度 8 段 |
| 组织诊断 | `org_portrait` 等 | 9 段式 |
| 舆情分析 | `opinion_event` 等 | 7 段式 |
| 组合 | 同时命中 ≥2 哨兵 | 按作者源序拼接 |

### 写作铁律（写每篇都要守）
案例先行 / 概念 ≤3（特殊 ≤4）/ 事实驱动 / 冲突式标题 / 禁"第一层第二层"分层列举 / 必写可传播金句 / 价值中立 / 附录来源必须 `[名称](url)` 可点击。
**第一章固定「情况概述」**，须交代：是什么、讲什么、结论是什么。

## 后端（backend/app，FastAPI ~5244 行）
- **入口** `main.py`：CORS（仅放行 3000，无害保留）、统一异常处理、startup 建表+种子+`recover_interrupted()`+`start_workers()`。
- **内核接线** `engine_bridge.py`：`ENGINE_DIR` 经 sys.path 注入 → `import engine` 黑盒调用，绝不重写内核。
- **任务流** `routers/analyze.py`：`POST /api/analyze`（提交任务）→ 工人池执行 → `WS /ws/progress/{id}` 实时进度 → `GET /api/analyze/{id}` 取结果 → `GET /api/download/{id}?kind=word|pdf&version=` 即时渲染下载（支持人工修订版回渲）。
- 其他路由：tasks / search / cases / reports / projects / materials / settings / system。
- 关键模块：`search.py`(BING→BRAVE→DuckDuckGo 零 Key 降级)、`generator.py`(web_mode 联网写稿 / revise 再改)、`prompt_builder.py`(5 类型哨兵护栏)、`contract.py`(生成后契约校验)、`queue.py`(数据库即队列+崩溃恢复)、`rule_engine.py`(13 条写作铁律校验)。

## 使用路径
1. **命令行**：`cases/run_*.py`（复制 `run_report.py` 模板）→ `engine.export_from_text(..., overwrite=True)` → `reports/`。
2. **后端 API**：双击 `start.bat` → `http://127.0.0.1:8000/docs`（前端移除后待重建界面再接）。
