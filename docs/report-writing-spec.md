# 三元结构理论报告写作规格 v1.0（Codex / 平台 LLM 执行手册）

> 用途：本规格是平台所有生成报告（事件 / 政策 / 组织 / 舆情 / 组合）的统一写作基准。
> 触发：用户反馈"信息太多太乱 / 不像之前自己写的干净"时，按本规格重新对齐，不重写报告本身去"修补"。
> 基准正例：`reports/方星海被查事件_任期政策取向与量化交易支持逻辑评估_20260728_005158/`（7–8 千字，干净透亮）。

---

## 0. 一句话总纲

**报告是"分析骨架"，不是"素材搬运"。素材只允许出现在事实摘要（3–6 条关键事实）和附录（`[来源名](url)`）。报告的价值在于把素材变成结构，而不是证明"我抓到了素材"。**

---

## 1. 执行流水线（写报告前必须按序走完）

| 步骤 | 动作 | 产出 | 检查点 |
|---|---|---|---|
| S1 素材归集 | 把抓回的素材/原文全部读一遍 | 素材要点清单 | 每篇素材提炼 ≤5 条关键事实，标出来源 url |
| S2 素材清洗 | 删冗余段落、重复信息、口水话；同一事实多条来源时保留最权威一条 | 干净事实池（10–20 条） | 事实池里没有完整段落复读 |
| S3 三张清单 | 主体 / 利益 / 关系 三张内部清单（见 §2） | 三张表 | **没填完不准开正文** |
| S4 定命题 | 用一句话写"核心命题"（现象的反面 + 结构判断） | 核心命题句 | 见 §3.3 正例 |
| S5 搭骨架 | 按 §3 章节顺序列出大纲，标注每章要用的事实条目编号 | 章节大纲 | 每章 2–6 个要点，不超页 |
| S6 逐章写 | 从"情况概述"开始，一章写完再写下一章 | 报告草稿 | 每章遵守 §3 对应规格 |
| S7 抽图 | 从正文抽出关系图谱（节点/边），生成 vis.js + png | 图 1–N（html + png） | 每张图正文里必须被引用（"图 N …"） |
| S8 自检 | 按 §7 交付自检清单逐条打勾 | 干净报告 | 任何一条不过 = 不发 |

## 2. 三张内部清单（必做，不写进报告）

> 这三张表是**写作过程**，不是**报告内容**。写正文前必须填完。下面用"华为竹知了事件"做完整示范。

### 2.1 主体清单（5–7 个，含角色）

| # | 主体 | 角色（在事件中的身份） |
|---|---|---|
| 1 | 华为 / 鸿蒙智行（法务） | 维权方：批量投诉发起者 |
| 2 | 余承东（个人 IP） | 被玩梗对象：形象资产的持有人 |
| 3 | 普通创作者 / 玩梗网民 | 二创主力：表达自由的承担者 |
| 4 | 恶意侵权者 / 职业 KOL | 黑流量链：受益于情绪对立 |
| 5 | 短视频 / 电商平台 | 流量与合规的平衡者：审核执行方 |
| 6 | 蹭热点商家 | 反向套利者：销量 6 倍暴涨的受益方 |
| 7 | 媒体 / 官媒（浙江宣传等） | 定调者：价值讨论的引导方 |

### 2.2 利益清单（每个主体在争什么 / 避什么 / 付什么成本）

| 主体 | 在争（想要的） | 在避（怕的） | 付的成本 |
|---|---|---|---|
| 华为 | 商誉与法律正义的确认 | "以大欺小"的公众形象 | 法律成本 + 舆情逆反 |
| 余承东 | 个人形象不再被丑化 | 形象持续受损 | 沉默（未公开回应） |
| 普通创作者 | 玩梗与表达的自由空间 | 被误伤、被追责 | 视频下架风险 |
| 恶意 KOL | 流量、热度、变现 | 被识破为黑公关 | 法律追责风险 |
| 平台 | 流量活跃 + 合规安全 | 被看作帮凶 / 过度管控 | 审核与申诉成本 |
| 商家 | 蹭热度的销量暴涨 | 侵权连带责任 | 改名、下架风险 |
| 媒体 | 话语权、价值观引导 | 被指带节奏 | 公信力风险 |

### 2.3 关系清单（两两之间：合作 / 对抗 / 中立 / 交换）

| A | B | 关系 | 说明 |
|---|---|---|---|
| 华为 | 恶意 KOL | 对抗 | 投诉对象 |
| 华为 | 普通创作者 | 对抗（但边界模糊） | 投诉误伤了温和玩梗者 |
| 华为 | 平台 | 交换 | 用投诉换平台配合下架 |
| 普通创作者 | 蹭热点商家 | 合作 | 梗被商家变现利用 |
| 恶意 KOL | 普通创作者 | 混同 | 恶意内容混在玩梗里难以区分 |
| 媒体 | 华为 | 中立→对抗 | 从质疑到引导价值讨论 |

## 3. 章节规格（逐章执行）

### 3.1 情况概述（首章，固定）

- **职能**：交代三件事——① 这是什么题材/对象；② 本篇在讲什么范围；③ 核心结论前置。
- **写法**：自然散文，不分条戳章、不用小标题堆砌。2–4 段，每段 3–5 句。
- **字数**：200–400 字。
- **正例**（对齐节奏，非复制）：
  > "胖猫事件不是关于'谁对谁错'的真相之争，而是关于'谁的叙事有权定义这场死亡的意义'的意识形态战争——一个人的真实死亡被拆解为五个互不相认的意义碎片。"
- **反例**（禁止）：
  > "开卷先看这四点：① 背景；② 经过；③ 结果；④ 结论。"（填充清单）

### 3.2 事实摘要（第二或并入首章）

- **职能**：纯事实，零分析。**只取 3–6 条关键事实**（不是把所有素材铺开）。
- **写法**：时间线/要点列表 + 每条末尾 `（来源：xxx）`。
- **字数**：400–800 字。
- **反例**（禁止）：整段贴抓回原文（梅花网/凤凰网整文复读）——这是本次"乱"的头号病根。

### 3.3 分析框架说明（含核心命题）

- **职能**：一句话点透本质。
- **核心命题句法**：`「现象A」不是「表象解释」，而是「结构解释」`，可以加一句"它揭示了…"。
- **正例**（惠州，用户原句）：
  > "惠州这两份政策构成的是一个'成长阶段奖补系统'而非'起步阶段支持系统'。……一人公司在政策结构里处于'够得着法人资格、够不着奖补门槛'的夹层。"
- **正例**（凌肖，用户原句）：
  > "凌肖维权事件不是孤立的'玩家闹事'，而是叠纸公司内部两套产品体系之间利益冲突的外溢表现。"

### 3.4 利益主体识别（表格）

- **职能**：把三张清单的主体+利益+关系转成报告可见的表格。
- **形式**：`主体 | 角色 | 核心利益 | 成本` 表 + 一段关系说明。
- **反例**（禁止）：
  > "（未提供具体主体，以下仅按已给事件做结构占位）"——这是承认失败。

### 3.5 核心冲突点（3–5 条，带编号）

- **句法**：每条必须为 `【主体A】对【主体B】在【利益X】上的张力：一句话展开`。
- **数量**：3–5 条。**少于 3 条=没分析透；多于 5 条=没提炼**。
- **正例**（竹知了示范）：
  1. 【华为】对【普通创作者】在"维权合法性"上的张力：投诉有理但误伤玩梗，把"对的事"做成"难看的事"。
  2. 【华为】对【恶意 KOL】在"侵权认定"上的张力：法务证据齐全，但举证难度与舆情速度不对等。
  3. 【平台】对【华为】在"下架执行"上的张力：平台配合维权，却被公众视为"帮凶"。
  4. 【蹭热点商家】对【华为】在"品牌借用"上的张力：商家借梗变现，责任却由华为品牌承担。
  5. 【媒体】对【公众】在"定调权"上的张力：官媒引导价值讨论，网民更在意情绪宣泄。
- **反例**（禁止）：
  > "（未单独标注冲突点。可从…推断主要矛盾；建议在关系步骤补充…）"——占位符 = 失败。

### 3.6 三元结构分析正文（按"主体 → 利益 → 关系"递进）

- **职能**：每个主体/利益组独立成节，节内按固定节奏展开。
- **一节四步**（每节内部节奏）：
  1. **事实锚点**：1–2 句客观事实（从事实池取）。
  2. **成本-收益核算**：1–2 句，这个主体在算一笔什么账。
  3. **行为解释**：1 句 `他不是…而是…`（给行为一个结构化的动机）。
  4. **结构归因**：1 句，把个体行为归到制度/结构层面。
- **正例**（甲酰胺"企业的成本账"，用户原句）：
  > "甲酰胺不是纸尿裤的必需成分，它是生产过程中发泡剂或交联剂的残留物。（事实锚点）这意味着企业完全可以通过更换原料或增加后处理工序来消除甲酰胺，但这会增加成本。（成本核算）当合规成本为零、安全成本为正时，市场不会自动选择安全。（结构归因）企业不是道德败坏，它们是在现有制度激励下做出了最'理性'的选择。问题不在企业的良心，在制度让良心变成了成本。（反转让洞察）"
- **正例**（胖猫"关系续费"，用户原句）：
  > "他持续转账不是因为被 PUA，而是因为不转账他就'没有资格'维持这段关系——而失去这段关系，他就没有任何关系了。转账是他的'关系续费'。→ 胖猫不是被害者，他是一个用钱购买情感续费的孤独者。"
- **禁止**：按时间线罗列事件、复读素材原文、每节无结论。

### 3.7 结论与推导（汇流段 + 核心判断 + 博弈终局）

- **汇流段**（150–250 字散文）：把各主体的判断"汇流"——他们不是在争静态对错，而是争夺"同一套规则下谁的利益先被计价"。**必须出现 2–3 个具体主体名**，禁止抽象名词堆砌。
- **核心判断**（一句话）：格式 `X 的本质不是「A」，而是「B」`。
  - 正例（甲酰胺，用户原句）："纸尿裤的甲酰胺问题不是'企业违法'的问题，它是'合法但有毒'的问题。"
- **博弈终局预判**（3–5 条）：每条 = 走向 + 触发条件 + 对谁影响。
  - 正例（政府工作报告）："① 政策红利持续向头部集中（触发：规模门槛不变）；② 一人公司转向'借壳'路径（触发：奖补兑现困难）；③ 监管从入口挪向出口（触发：事后抽查常态化）。"

### 3.8 行动建议（可执行条目，按主体分块）

- **形式**：按主体分块，每方 2–3 条；每条 = 动词开头 + 针对利益 + 约束条件。
- **正例**（竹知了示范）：
  - 对华为：① 明确"投诉四类侵权"的边界并公开展示，避免误伤温和玩梗（约束：保留 171/144 数据的可核验口径）；② 用"以段治段"回应一次玩梗，置换"强势维权"的公众印象。
  - 对平台：① 区分"恶意侵权"与"普通玩梗"两条申诉通道，公开复核标准；② 对商家蹭热点改名做侵权预警，避免连带责任。
  - 对媒体：① 把讨论从"该不该投诉"引向"维权与表达自由的边界如何划定"；② 引用可核验数据，避免被指带节奏。
- **反例**（禁止）：
  > "（未提供具体行动建议。可基于结论自行制定…建议在向导补充。）"——占位符 = 失败。

### 3.9 附录（来源列表）

- **形式**：`[来源名](url)`，每条一行，按权威度排序。
- **反例**（禁止）：
  > "数据来源：（结构化输入模式，来源由录入者补充；本节不虚构任何未提供的出处）"——占位符 = 失败。

## 4. 图表规范

- **必须**：从正文抽出关系图谱（vis.js 交互 html + networkx png 各一份），节点写"是谁 + 角色"，边写"关系类型（合作/对抗/中立/交换）"。
- **数量**：每份报告 ≥1 张全景利益关系图；复杂案例按"主体视角"分图（如胖猫 4 张）。
- **引用**：正文必须出现"图 N …"文字引用，图题与正文小节对应。
- **没有图的关系分析 = 不交付。**

## 5. 字数与信息密度

| 类型 | 参考区间（实测 9 篇） | 说明 |
|---|---|---|
| 事件型（胖猫/甲酰胺） | 8–9K 字 | 干净、紧凑 |
| 政策型（惠州/广东/政府） | 17–37K 字 | 事实密度高，章节多 |
| 组织型（蜜雪） | ~20K 字 | 组织画像 + 三元张力 |
| 深度案例（凌肖） | ~46K 字 | 时间线极详细时允许，但须每段有分析 |

**判定规则**：全文 >30K 字时必须自查——"哪些段落是素材复读？哪些能砍成一句事实锚点？"超过一半页面没有任何分析句 = 判定为乱。

## 6. 风格红线（可判定规则）

1. 禁出现"开卷先看这四点 / 最强结论 / 最稳的判断 / 三点思考"等填充清单句式。
2. 禁出现"（未提供…）/（未单独标注…）/（建议在…补充）"占位符——这是承认失败。
3. 禁"是否定的"自我吐槽占位句。
4. 标题必须基于事实自拟：`事件/对象 + 视角/结构词`（如"胖猫事件的五主体叙事博弈分析""甲酰胺事件的多主体制度博弈分析"），**禁复读用户输入标题**。
5. 禁按时间线写三元分析正文（时间线只允许出现在事实摘要）。
6. 禁任何"结论靠猜"的表述：无法验证的事实须标注"（来源：xxx）"或列入附录。

## 7. 交付自检清单（10 条，一条不过 = 不发）

- [ ] 1. 全文无整段素材/原文复读（只在事实摘要取 3–6 条关键事实）
- [ ] 2. 无任何"（未提供…）/（未标注…）/（建议补充…）"占位符
- [ ] 3. 首章是"情况概述"自然散文（题材/范围/结论前置三件事齐全）
- [ ] 4. 核心命题一句话，格式"不是…而是…"
- [ ] 5. 核心冲突点 3–5 条，每条 `【A】对【B】在【利益X】上的张力`
- [ ] 6. 三元分析正文按"主体 → 利益 → 关系"递进，每节有"四步节奏"和一句洞察
- [ ] 7. 结论含"汇流段（≥2 个具体主体名）+ 核心判断（一句话）+ 博弈终局预判（3–5 条）"
- [ ] 8. 行动建议按主体分块，每方 2–3 条可执行条目
- [ ] 9. 附录为 `[来源名](url)` 格式，每条一行
- [ ] 10. 有 ≥1 张关系图谱（html + png），正文引用了图号

## 9. 用户说"乱"时 Codex 的处理流程

1. 先按 §7 自检清单逐条比对报告，找出违反项（不要直接重写）。
2. 把违反项以"违反了 §N 第 M 条：具体例子"的形式报给用户。
3. 与用户确认改哪几条，再按 §1 流水线重跑。
4. 未经用户确认，不得整体推翻重写。
