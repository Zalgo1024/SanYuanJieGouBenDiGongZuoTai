# 分析输入帮助与生成温度说明设计

## 目标

让第一次使用工作台的人在不离开当前任务的情况下理解两件事：生成温度控制什么，以及怎样写出足以启动分析的问题。帮助内容必须可跳过，不能阻塞熟练用户。

## 生成温度

- 保留现有 `0-2` 数字输入和 `0.3` 默认值。
- 在控件下永久显示“控制表达随机性，不代表分析深度”。
- 按当前值显示可理解的状态：`0-0.2 严谨稳定`、`0.3-0.5 均衡分析`、`0.6-0.8 发散表达`、`0.9-2 创意探索`。
- 明确标注正式研究报告建议 `0.2-0.4`，避免用户误以为数值越高质量越高。

## 新建分析教程

- 标题区提供可展开的“查看输入教程”，默认收起，不遮挡输入。
- 展开后说明最小输入结构：分析对象、希望回答的问题；时间范围、决策身份、重点主体和材料属于增强项。
- 教程随分析类型切换事件、政策、组织、舆情和组合分析示例。
- 提供“填入示例”命令，直接把对应示例放入真实输入框，不建立独立教程模式。
- 桌面端右侧改为“提交前检查”；移动端保留可展开教程，右侧检查区可隐藏。

## 约束与验收

- 不新增后端接口、依赖、弹窗或强制导览。
- 不改变任务提交数据结构和现有材料、联网检索、分析用途控件。
- 帮助文案在桌面与移动端不溢出，键盘可操作，展开状态使用原生语义。
- 自动化测试覆盖温度档位、动态示例和“填入示例”。
