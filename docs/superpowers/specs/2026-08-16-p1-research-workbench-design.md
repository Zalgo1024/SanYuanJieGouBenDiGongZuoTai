# P1 研究工作台设计

## 一、目标

把当前一次性报告与关系图谱升级为本地、证据驱动、可复盘的研究工作台。P1 不增加新的理论章节，集中深化主体、利益、关系、时间、来源和可靠性。

## 二、设计原则

1. 后端研究快照是唯一真源，前端不得根据正文猜测权重、关系或变化。
2. 所有新字段向后兼容。旧报告缺字段时显示“未知”或“尚未建立”，不能补造。
3. 质量不再压缩成一个“100 分”，只展示可解释指标及其计算口径。
4. 持续追踪复用现有分析队列、搜索和生成流水线，不另写第二套分析引擎。
5. 自动追踪只绑定本地项目，默认关闭；同一监测器同时最多运行一个任务。

## 三、研究快照 1.1

`ResearchLedger` 增加以下结构：

- 来源：规范化域名、来源质量等级、评级理由、内容指纹、重复来源指向、原始出处 URL。
- 主体档案：主体名称、角色、利益、当前立场、权重、置信度、证据、首次与最后出现时间、立场历史。
- 关系：1 至 5 级强度、利益类型、方向、正负极性、确定/推测/冲突、起止时间、证据数量。
- 时间线：日期、事件、主体、证据、置信度、是否关键转折点。
- 资料缺口：优先级、所需资料类型、影响范围和建议补充材料。
- 可靠性指标：来源覆盖、独立来源、事实引用、关键判断覆盖、关系证据覆盖、时间完整度、未证实推断、冲突和资料缺口。

来源分类和去重由确定性代码执行。LLM 可以提出来源类型和主体结构，但不能修改应用持有的 URL、来源 ID、内容指纹和重复关系。

## 四、关系图谱分析

图谱渲染使用研究快照增强原有 DIAGRAM：

- 节点尺寸映射主体权重；节点档案显示角色、利益、立场、时间范围、证据和相关判断。
- 连线宽度映射关系强度；箭头映射方向；颜色和标签展示利益类型与正负极性；虚线表示推测关系。
- 点击关系显示“为什么认为 A 与 B 存在关系”：对应判断、推理说明、支持与反向证据、来源等级、时间范围和置信度。
- 无账本或无法匹配时保留原图，并明确提示没有边级分析数据。

## 五、时间与变化

新增确定性快照比较器，比较任意两份研究账本：

- 新增、消失的主体和关系；
- 关系强度、极性、状态和置信度变化；
- 主体立场变化；
- 新增、撤回或置信度改变的关键判断；
- 新来源、冲突变化和资料缺口变化。

报告页历史版本选择器旁展示版本差异。项目页展示不同分析任务之间的最近变化。时间线按日期排序，缺少可靠日期的项目单列为“时间未知”。

## 六、持续追踪

新增本地 `ResearchMonitor`：项目、种子任务、启用状态、间隔小时、上次与下次运行时间、最近任务、最近变化摘要。后台轻量调度器每分钟检查到期监测器，并复制种子任务创建一次联网分析。手动“立即复盘”使用同一入口。

任务完成后，系统比较本次与该监测器上一份成功快照并保存变化，提示新主体、关系改变、判断变化、资料缺口和风险代理变化。监测失败保留错误，不覆盖上一份成功结果。

## 七、报告阅读与质量

报告阅读器提供三种模式：

- 快速版：核心判断、证据、不确定性、含义、最高优先级资料缺口。
- 标准版：核心判断加精简章节，重复章节默认折叠。
- 完整研究版：完整正文、来源、时间线、质量指标和全部缺口。

现有写作质量闸门继续负责格式与必要章节，但 UI 不再展示不可解释的总分。研究可靠性面板只展示有明确分母和计数的指标，并说明“未知”原因。

## 八、错误与边界

- 没有 LLM 或结构提取失败时生成 `fallback` 快照，所有新增分析字段保持未知或低置信度。
- 来源冲突并排展示，不自动裁决。
- 监测运行中禁止重复触发；项目归档后暂停自动运行。
- 不引入云端数据库、账户、收费或外部定时服务，数据仍全部保存在本机 SQLite。

## 九、验收

1. 新账本能识别来源类型、评级、重复组并计算可解释指标。
2. 图谱节点和关系具有分析属性，点击关系能回答证据与推理链。
3. 两份快照可确定性计算变化，报告页和项目页均可查看。
4. 项目可开启、暂停、手动运行持续追踪，自动任务复用现有队列。
5. 报告支持快速、标准、完整三种阅读模式，不显示“质量分 100”。
6. 旧报告、旧数据库、规则模式和既有导出流程保持可用。
