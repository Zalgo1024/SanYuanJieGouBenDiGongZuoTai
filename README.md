## ⚡ 它是什么

一个**方法论驱动**的结构化分析引擎：以三元结构理论（生存 — 繁衍 — 逆反 — 利益 四维框架）为内核，
把输入的政策文件、社会事件、组织样本、舆论场，拆解为**可检验、可追溯、可交付**的结构化报告。

- **不是聊天记录** —— 产出的是 Word / PDF / 交互式 HTML / PPT 四种正式交付物
- **不是抽奖式输出** —— 证据绑定判断、来源规范、章节结构由内核强制校验
- **不是黑盒** —— 方法论、渲染器、利益网络图，全部开源可审查

> 已用真实案例跑通闭环：山西大同事件、一人公司政策分析、商标法修订分析等
> 多份验证报告，均为 AI Agent 在框架约束下自动产出。

## 🧭 四种分析模式

| 模式 | 结构 | 适用对象 |
|---|---|---|
| 政策分析 | 8 段式 | 法规、文件、制度文本 |
| 事件 / 案例分析 | 5 段式 / 深度 8 段式 | 社会事件、舆论热点 |
| 组织诊断 | 9 段式 | 组织、公司、机构 |
| 舆情分析 | 7 段式 | 舆论场、叙事竞争 |

支持**组合分析**：多模式章节按书写源序拼接，一份报告同时覆盖舆情 + 组织 + 政策多个维度。

## 🎯 核心能力

1. **利益关系网络** —— D3.js 力导向图，六类利益配色（物金 / 安绿 / 政紫 / 身份橙 / 制度蓝 / 公共青）、四类关系链线型，一眼看清主体间的张力结构
2. **写作规范兜底** —— 禁止 EVD 编号、禁止机械分层、禁止万能套话，从约束层保证输出质量稳定
3. **版本留痕** —— 每次生成留存版本，可回溯、可编辑、可下载
4. **联网检索降级链** —— BING → Brave → DuckDuckGo，零 Key 也能检索
5. **BYOK 架构** —— 访客自带 API Key，服务器不持有、不存储任何模型密钥，部署方零密钥成本、零额度风险

## 🏗️ 系统架构

```
┌─────────────────────────────────────────────────────────┐
│                  Next.js 15 前端工作台                     │
│   分析 / 项目 / 报告 / 利益网络 / 设置 / 实时进度 (WebSocket) │
└───────────────┬─────────────────────────┬────────────────┘
                │ /api                    │ /ws
┌───────────────▼─────────────────────────▼────────────────┐
│               FastAPI 后端（SQLite）                       │
│   任务队列 · 联网检索 · 提示词装配 · 契约校验 · 版本留痕        │
└───────────────┬───────────────────────────────────────────┘
                │ engine.export_from_text()
┌───────────────▼───────────────────────────────────────────┐
│          分析内核（纯 Python，可独立运行）                   │
│   parser → 三元结构分析 → docx / pdf / viz_network          │
└───────────────────────────────────────────────────────────┘
```

- 前端 / 后端 / 内核三层解耦：内核可以脱离 Web 独立使用
- 单容器 Docker 部署（Caddy 反代），支持 Render Blueprint 一键上线

## 🚀 快速开始

### 1 · 本地工作台（Windows）

```
双击 start.bat
```

| 入口 | 地址 |
|---|---|
| 前端工作台 | `http://127.0.0.1:3000` |
| 后端 API 文档 | `http://127.0.0.1:8000/docs` |

### 2 · 命令行内核（纯 Python）

```python
from engine import export_from_text

export_from_text(markdown_text, title="你的分析标题")
```

### 3 · 服务器部署（Render / Docker）

仓库内置 `Dockerfile` + `render.yaml`：

- Render 控制台 → **New → Blueprint** → 选择本仓库 → **Apply**，即可上线
- `PUBLIC_MODE=1` 开启 BYOK：访客在浏览器里自助填自己的 API Key，服务器不碰任何密钥
